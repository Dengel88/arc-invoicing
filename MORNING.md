## Шаг 1. ⚠️ Завести USDC на Arc — это блокер, начни с него

**Без этого ничего не задеплоится.** На Arc газ платится в USDC, и пустой кошелёк не
может отправить ни одной транзакции.

Сколько нужно на самом деле — я измерил, а не прикинул:

| Операция | Газ | Стоимость |
|---|---|---|
| Деплой контракта | 1 528 053 | **≈ 0.061 USDC** |
| Создать счёт | ~200 000 | ≈ 0.008 USDC |
| Оплатить счёт | ~80 000 | ≈ 0.003 USDC + сама сумма счёта |

То есть по делу нужно меньше 10 центов. Но биржи не дадут вывести 10 центов — у них
минимальная сумма вывода обычно 10–20 USDC. Реально ориентируйся на минимум биржи.

**Нужно два кошелька** (для демо: один выставляет счёт, второй оплачивает):

- Кошелёк A (продавец, он же деплоер) — сумма минимального вывода
- Кошелёк B (плательщик) — сумма минимального вывода + сумма тестового счёта

### Как получить USDC именно в сети Arc

Три варианта, выбери что тебе доступно:

1. **Вывод с биржи напрямую в сеть Arc.** Самый простой. Arc-вывод USDC поддерживают
   **KuCoin** и **Kraken** (обе подключили Arc в день запуска мейннета, 16 сентября
   2026). При выводе в списке сетей выбери **Arc**, не Ethereum и не Polygon.
2. **Мост Circle CCTP**, если у тебя уже есть USDC в другой сети (Ethereum, Base,
   Polygon и т.п.). Инструкция: <https://docs.arc.io/integrate/exchanges/cctp-bridging>.
   Адрес назначения — тот же самый EVM-адрес, Arc использует обычную адресацию.
   Учти: там есть шаг «attestation» от Circle, он занимает реальное время.
3. **Circle Mint** — для юрлиц, через банковский перевод. Долго, для сегодня не вариант.

> Я не знаю, какая из бирж тебе доступна и какие у неё лимиты — это надо проверить
> тебе. Если ни одна не подойдёт, напиши, подберём другой путь.

**Как убедиться, что деньги дошли** (подставь свой адрес):

```bash
cast balance 0xТВОЙ_АДРЕС --rpc-url https://rpc.mainnet.arc.io --ether
```

`cast balance` спрашивает у сети баланс адреса. Флаг `--ether` делит на 10¹⁸ —
на Arc нативный USDC как раз 18 знаков, так что число получится в USDC.
Должно быть больше нуля.

## Шаг 2. Прочитать контракт и прогнать тесты (10 минут)

Пока идут деньги, посмотри код своими глазами.

```bash
cd /d/AI/Kwork/ARcHakaton/contracts
forge test -vv
```

`forge test` компилирует контракт и прогоняет 37 тестов. Флаг `-vv` показывает каждый
тест отдельной строкой. Ждём в конце: `37 passed; 0 failed`.

Хочешь посмотреть покрытие:

```bash
forge coverage --no-match-coverage "test|script"
```

Должно быть 100% строк и функций, 90% веток.

Что читать глазами — `contracts/src/ArcInvoicing.sol`, там всего ~270 строк, и каждое
неочевидное решение объяснено комментарием прямо на месте. Главное, на что стоит
посмотреть: функция `payInvoice` — она `payable`, то есть деньги приходят в `msg.value`,
без всякого ERC-20 `approve`. В этом весь смысл «почему Arc».

## Шаг 3. Положить ключ деплоера в зашифрованное хранилище (2 минуты)

Приватный ключ нигде в проекте не лежит и лежать не должен. Foundry умеет держать его
в зашифрованном keystore и спрашивать пароль при подписи.

```bash
cast wallet import arc-deployer --interactive
```

Команда спросит приватный ключ кошелька A (ввод не отображается — это нормально),
потом пароль для шифрования. Ключ ляжет в `~/.foundry/keystores/arc-deployer`
в зашифрованном виде, а в историю терминала не попадёт.

Проверить, что импортировался нужный адрес:

```bash
cast wallet address --account arc-deployer
```

Должен напечатать адрес кошелька A. Если не совпал — импортировал не тот ключ.

## Шаг 4. Задеплоить контракт на Arc mainnet 🔑

**Сначала — репетиция без отправки.** Эта команда прогоняет весь деплой против живой
сети, но ничего не публикует (нет флага `--broadcast`):

```bash
cd /d/AI/Kwork/ARcHakaton/contracts
forge script script/Deploy.s.sol:Deploy --rpc-url https://rpc.mainnet.arc.io
```

Ждём `SIMULATION COMPLETE` и строку `Chain 5042`. Я это уже прогонял ночью — работает.

**Теперь боевой деплой:**

```bash
forge script script/Deploy.s.sol:Deploy \
  --rpc-url https://rpc.mainnet.arc.io \
  --account arc-deployer \
  --broadcast
```

Что происходит: `--account arc-deployer` берёт ключ из keystore (спросит пароль),
`--broadcast` отправляет транзакцию в сеть. Скрипт перед отправкой проверяет, что
`block.chainid` действительно Arc, а после — что по адресу реально появился байткод.

**Запиши адрес из вывода.** Он будет в блоке:

```
=====================================================
  ArcInvoicing deployed
  Address:      0x....
=====================================================
```

Проверить в обозревателе: `https://explorer.arc.io/address/0xВАШ_АДРЕС`

## Шаг 5. Подключить адрес к фронту и задеплоить на Vercel 🔑

```bash
cd /d/AI/Kwork/ARcHakaton/web
cp .env.example .env
```

Открой `web/.env` и впиши адрес из шага 4:

```
VITE_CONTRACT_ADDRESS=0xАДРЕС_ИЗ_ШАГА_4
```

Проверь локально, что фронт увидел контракт:

```bash
npm run dev
```

Открой `http://localhost:5173`. Жёлтая плашка «Contract address not configured» должна
**исчезнуть**, а внизу страницы появиться ссылка «Contract 0x…». Если плашка осталась —
адрес вписан с опечаткой. Останови сервер (Ctrl+C).

Теперь Vercel. CLI не установлен, ставим:

```bash
npm install -g vercel
```

Логин (откроется браузер, войдёшь своим аккаунтом — я к нему доступа не имею):

```bash
vercel login
```

Деплой в прод **из папки `web`**, это важно:

```bash
cd /d/AI/Kwork/ARcHakaton/web
vercel --prod
```

Vercel спросит несколько вещей:
- *Set up and deploy?* → **Y**
- *Which scope?* → твой аккаунт
- *Link to existing project?* → **N**
- *Project name?* → `arc-invoicing` (или как хочешь)
- *In which directory is your code located?* → **`./`** (ты уже внутри `web`)
- остальное — Enter, он сам определит Vite

⚠️ **Важно:** переменную окружения надо задать и на стороне Vercel, иначе на проде
плашка вернётся — локальный `.env` туда не уезжает:

```bash
vercel env add VITE_CONTRACT_ADDRESS production
```

Вставь адрес контракта, потом пересобери:

```bash
vercel --prod
```

Запиши полученный URL — он нужен для заявки.

## Шаг 6. Сделать демо-счёт и оплатить со второго кошелька 🔑

Это уже через сам сайт, не через терминал — заодно проверишь, что всё работает.

1. Открой задеплоенный сайт, подключи **кошелёк A** (продавца).
   Если MetaMask не знает сеть Arc, он предложит её добавить — согласись.
   Параметры на всякий случай: Chain ID `5042`, RPC `https://rpc.mainnet.arc.io`,
   валюта `USDC`, обозреватель `https://explorer.arc.io`.
2. В форме «New invoice»:
   - **Bill to** — адрес кошелька B
   - **Amount** — небольшая сумма, например `1.5`
   - **Reference** — что-нибудь осмысленное для демо, например
     `INV-2026-001 · Design retainer, Lisbon → Singapore`
3. Нажми **Issue invoice**, подтверди в кошельке. Счёт появится справа со статусом
   **Pending** (жёлтый).
4. Переключись в кошельке на **кошелёк B** (или открой сайт в другом браузере).
   Счёт покажется в списке с кнопкой **Pay 1.50**.
5. Нажми **Pay**, подтверди. Статус переключится на **Paid** (зелёный), а деньги
   придут на кошелёк A. Это одна транзакция — никакого `approve` перед ней нет,
   и это ровно то, что стоит показать в демо.

Если что-то пойдёт не так — ошибка будет написана человеческим языком в уведомлении
внизу справа, а не ABI-дампом.

хакатона: «A public repo»), без README/gitignore, их я уже написал.

Затем (подставь своё имя пользователя и название репозитория):

```bash

git branch -M main
git push -u origin main
```

Git спросит логин и пароль — вместо пароля нужен **Personal Access Token**
(GitHub давно не принимает обычный пароль). Создать: Settings → Developer settings →
Personal access tokens → Tokens (classic) → Generate new token, галочка `repo`.

Проверь на GitHub, что папка `contracts/lib/forge-std` отображается как ссылка на
сабмодуль, а `node_modules` и `.env` **не** попали.

## Если что-то сломалось

| Симптом | Что это значит |
|---|---|
| `forge: command not found` | Не выполнил шаг 0 (`export PATH=...`) |
| `insufficient funds for gas` | На кошельке нет USDC — шаг 1 |
| `Deploy: refusing to deploy outside Arc` | Неверный `--rpc-url` |
| На сайте жёлтая плашка после деплоя | `VITE_CONTRACT_ADDRESS` не задан в Vercel — шаг 5 |
| В кошельке «wrong network» | Нажми кнопку «Switch to Arc» на самом сайте |
| Баланс USDC в кошельке показывается странно | MetaMask может не знать про 18 знаков Arc. На балансе это не сказывается, только на отображении |
